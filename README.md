# TRICK OR TREAT : 

It's a halloween themed game which is basically having a score bar.. where the computer picks a random no. from 1 to 5 and if that's 1,2 or 3 u recieve a candy i.e +1 points, similar is to pumpkin if get the no. 5 that's pumpkin and u receive +3 points but if u get 4 then will loose one point and get trick.
The score will be visible there and I have setted up a reset button as well to reset the score and also there is button i.e open door to interact with the door. the door there is actually an emoji. 

## The purpose : 

The purpose build was for 3am ship - but I can say that I learned/revised functions and state concepts with this project. 

## Tech Stack : 
1. React
2. CSS

## How to run this locally ? :
1. git clone https://github.com/SrishtiOnGit/Halloween-Invitation.git
2. cd client
3. npm install
4. npm run dev
